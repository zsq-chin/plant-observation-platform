植物观察 App · 手机安装

手机需与电脑处于同一 WiFi。以下两种方式任选其一。

方式一：安装 APK（推荐，桌面图标）

下载 APK（3.9 MB）

扫码或点按钮下载后安装；华为手机需先允许「安装外部来源应用」。

方式二：浏览器直接打开（免安装）

打开网页版

浏览器菜单「添加到主屏幕」可获得类 App 图标。

安装与使用提示

  • 华为 P40 / HarmonyOS：设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 允许「浏览器」或「文件管理」
  • 演示账号：stu1 / admin123（学生）、tea1 / admin123（教师）
  • APK 为调试包（WebView 壳，实时加载局域网网页版），后端地址：http://10.120.46.175
  • 若打不开：确认手机与电脑同一 WiFi，且 Windows 防火墙允许 80 端口入站
