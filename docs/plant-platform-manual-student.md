# 全国植物观察与交流平台 — 学生用户手册（v1.0）

> **适用对象**：初中、高中学生（学生账号）
> **适用版本**：RC1 分支（Web 学生端 + 学生 Android App 共用同一账号与数据）
> **相关文档**：[App 构建安装说明](./student-app-android-build.md)｜[平台运维说明](./plant-platform-operations.md)

欢迎使用「全国植物观察与交流平台」🌿！你可以把身边见到的植物拍下来、记录下来，和全国的同学一起分享；审核通过的记录会进入**植物展廊**，任何人都能看见，还能互相评论、点赞式评分。本手册用最简单的话告诉你每一步怎么操作。

---

## 1. 简介与登录 🔑

### 1.1 平台由哪两部分组成？

| 部分 | 是什么 | 怎么打开 |
|------|--------|----------|
| **Web 学生端** | 用浏览器访问的网页版 | 打开浏览器，输入学校提供的网址（形如 `http://学校地址/jingxuan/`），访问「全国植物观察与交流平台」 |
| **学生 Android App** | 装在手机上的 App | 由老师发给你 APK 安装包安装（怎么从源码编译见 [student-app-android-build.md](./student-app-android-build.md)），或学校提供已装好的设备 |

> 💡 两个入口**共用同一个账号和同一份数据**：网页上保存的草稿，手机上登录同一账号也能看到，因为数据保存在服务器上，不是存在某一台设备里。

### 1.2 演示/练习账号

| 账号 | 密码 | 角色 |
|------|------|------|
| `stu1` | `admin123` | 学生（演示用） |
| `stu2` | `admin123` | 学生（演示用） |

登录后默认进入**学生端**（学生的专属工作台）。

### 1.3 Web 端怎么登录？

1. 打开网址，进入平台**首页**（顶部导航依次是：**首页｜植物展廊｜中国地图｜物种库**）。
2. 点右上角 **「账户入口」**，再点 **「登录」**（未登录时显示的是“登录”）。
3. 在「账户登录」页面输入**学号/用户名**（如 `stu1`）和**密码**（如 `admin123`），点 **「登 录」**。
4. 登录成功后自动进入**学生端（学生工作台）**，左侧菜单里有：首页、我的待办、**我的植物观察**、旧·作品管理、我的评分、**消息通知**。

> ⚠️ 若是**首次登录**，系统会提示先修改密码（跳转到「修改密码」页），改完再继续使用。密码请自己保管好，不要告诉别人。

### 1.4 App 怎么登录？

1. 打开 App，进入「登录」页（标题为“全国植物观察与交流平台 · 学生端 · 记录身边植物”）。
2. 在 **「学号 / 用户名」** 输入框填账号（如 `stu1`），在 **「密码」** 输入框填密码（如 `admin123`）。
3. 点绿色 **「登 录」** 按钮，提示“登录成功”后自动进入「首页」。

> 🔒 登录后，账号密码会自动保存在手机上（**不会保存明文密码**），下次打开不用重新输入；如果要在公用设备上使用，记得在「我的 → 退出登录」退出。

## 2. 首页与展廊浏览 🌸

### 2.1 App 底部导航

App 底部有 5 个常驻入口：

**首页 ｜ 展廊 ｜ 采集 ｜ 我的植物 ｜ 我的**

- **首页**：欢迎语（“你好，××”）、统计数据（**待完善 / 待审核 / 已通过 / 被驳回**）、大按钮 **「＋ 采集植物」**、「最新优秀观察」列表，以及「快捷入口」：**植物展廊、全国植物、消息、新物种建议**。
- **展廊**：公众展示页（见 2.2）。
- **采集**：现场拍照保存草稿的页面（见第 3 章）。
- **我的植物**：自己全部记录的管理页（见第 4 章）。
- **我的**：个人信息 + 新物种建议、消息通知、退出登录。

### 2.2 植物展廊（公众页）

展廊里的记录都是**已通过教师审核**的公开观察，任何人都能浏览：

- **Web 端**：点顶部导航 **「植物展廊」** 进入「植物观察展廊」页。可以用 **「搜索植物 / 学名 / 学生姓名」** 搜索，还能按**省份、类别、班级、年份**筛选，按 **精选优先 / 最新发布 / 浏览最多** 排序，点 **「搜索」/「重置」** 应用条件。
- **App 端**：点底部 **「展廊」**，顶部输入框可**搜索植物 / 学名**，列表底部有 **「加载更多」**。

每张卡片会显示：植物名称、学名、📍省/市、👤观察者、📅观察时间、⭐评分、💬评论数、👁浏览数；**教师精选**的记录带 **「★ 优秀观察」** 角标。

点击卡片进入**观察详情**页，可以看到：
- 多张照片（Web 端可点开看大图）；
- 观察地点、观察时间、观察者与班级；
- 「观察描述」与教师配置的**动态描述项**（如“花期”“叶形”等，教师自定义）；
- 「💬 教师审核意见」（如果有）；
- 「评论与点评」区：**登录后**才能**发表评论**（未登录会提示“登录后可评论与评分”）；
- 「综合参考价值」：⭐ 平均分、评价人数、评论数与浏览数，登录后可点 **「我要评分」**（选 1～5 星）。

> 🤝 请用友善、认真的语气评论他人的观察，平台要求“友善交流”。

## 3. 采集一条植物观察 📷（核心流程）

一条植物观察的完整旅程：

> **拍照 → 补充信息（地点 / 植物 / 时间 / 描述）→ 保存草稿 → 提交审核 → 教师审核通过 → 进入展廊**

### 3.1 方法一：App 现场采集（推荐外出观察时用）

打开 App，点底部 **「采集」**（或首页大按钮 **「＋ 采集植物」**），页面从上到下是：

1. **① 照片（0/10）**：最多 **10 张**。点 **「📷 拍摄」** 现拍，或点 **「🖼 相册」** 从手机相册多选；点照片右上角 **×** 可删掉重拍。
   - App 会**自动压缩照片**再上传（默认压缩到 75% 质量），既省流量又不会太大传不上去。
2. **器官类型**：给这批照片贴一个部位标签，可点选：**全株 / 叶 / 花 / 果实 / 树皮 / 种子 / 其他**（例如只拍了叶子就选“叶”）。
3. **② 地点（主动选择，不获取定位）**：点 **「请选择省 / 市 / 区县」** 弹窗逐级选择省、市、区县；下面还有 **「详细地点（可选）」** 输入框，可以写“校园植物园东侧”这样的提示。
4. 点底部 **「保存草稿」**。
   - 网络正常：保存成功并逐张上传照片 → 自动跳到「我的植物」；
   - 网络差/没网：系统会提示“网络不可用，已存为本地草稿”，照片先存在手机里，**等联网后再补传**（见 3.3）。

保存后回到**我的植物 → 待完善**，点这条记录，进入「补充观察」页继续填内容，填好后点 **「提交审核」**（详细填法见 3.3）。

### 3.2 方法二：Web 端（适合回家用电脑慢慢整理）

1. 登录后，在左侧菜单点 **「我的植物观察」**。
2. 点右上角 **「＋ 新增植物记录」**，进入「新增植物观察」页。
3. **先点一次「保存草稿」**（系统会先生成一条草稿记录）——Web 端上传照片前需要先有这条草稿，如果直接传照片会提示“请先保存草稿，再上传照片”。
4. 再按下面的表单逐项填写（各字段含义见 3.3），完成后点 **「提交审核」**。

> 页面顶部也有一句话提示：**“现场先拍照片、选地点保存草稿，回家后可继续补充植物信息再提交审核。”**

### 3.3 各字段是什么意思？（Web 与 App 通用）

| 字段 | 含义与填写建议 |
|------|----------------|
| **植物照片（1~10 张）** | 只支持 JPG/PNG/WebP/GIF；**第一张（最先上传的）会自动成为封面**，展廊卡片上显示的就是它。目前页面还没有“设为封面/拖拽排序”按钮，想让哪张当封面，就把它放在最前面上传。 |
| **器官类型（App 采集页）** | 这批照片拍的是植物的哪个部位（全株/叶/花/果实/树皮/种子/其他），方便别人看图。 |
| **省 / 市 / 区县** | 观察发生地，**必须手动三级选择**。系统**不会读取你的设备定位**（不采集 GPS），这是为了保护隐私。 |
| **详细地点（可选）** | 写大概位置即可（如“操场西侧花坛”）；**不要写具体门牌号、家庭地址**。 |
| **标准植物** | 在物种库里搜索匹配，输入框支持搜**中文名/学名**（如“银杏、桂花”），点选后自动填上中文名与学名。选不到也没关系，见第 6 章“待鉴定”。 |
| **上报名** | 没匹配到标准植物时手动填的名字，比如“路边的黄花灌木”。 |
| **观察时间** | 选择/填写这次观察发生的时间（Web 页为“选择观察/采集时间”）。 |
| **动态描述项（教师配置）** | 老师自定义的补充项（选择、多选、开关、日期、数字、文字等），带红色 ＊ 的是必填项，不填全无法提交审核。 |
| **基础描述** | 用几句话写这株植物的**形态、生境、发现经过**（最多 5000 字）。 |

Web 端两个按钮：**「保存草稿」**（存着以后继续）和 **「提交审核」**（直接送老师审核）。App 的「补充观察」页同样有 **「保存草稿」「提交审核」**。

> ⏳ 提交审核时系统会检查：至少 1 张照片、已选省份、填了观察时间、必填描述项齐全（“未知植物”除外，见第 6 章），不满足会提示缺少什么，补好再提交即可。

## 4. 我的植物与状态说明 📒

进入方式：Web 左侧菜单 **「我的植物观察」**；App 底部 **「我的植物」**。

页面按**状态 Tab** 分类（Web：**全部 / 草稿 / 待审核 / 已通过 / 被驳回**；App 在此基础上多一个 **本地草稿**，且把“草稿”称为 **待完善**）：

| 状态 | 含义 | 你可以做什么 |
|------|------|--------------|
| **草稿（App 显示“待完善”）** | 还没提交，只给自己看 | 继续编辑、提交审核、删除 |
| **待审核** | 已提交，在排队等老师审 | 撤回（变回草稿）、查看；不能改内容 |
| **已通过** | 审核通过，已在展廊/地图公开 | 只读查看；若被管理员下线会变成“已下线” |
| **被驳回** | 老师没通过，已退回 | 修改后**重新提交**，或删除 |
| **已下线** | 管理员强制下线，不再公开展示 | 只读查看（一般不会遇到） |

列表里每条记录会显示：植物名（未填时显示“未命名植物/待鉴定/未命名”）、状态标签、📍省市县、📅时间、简短描述。行内按钮（按状态出现）：

- **继续编辑** —— 打开这条记录补充/修改；
- **提交审核** —— 把草稿或被驳回的记录送审（App 上点完提示“已提交”）；
- **撤回** —— 把“待审核”的记录撤回成草稿（提醒：只在自己还没被审核前有意义）；
- **删除** —— 只对“草稿/被驳回”记录可用，删除后照片会一并清除（App 会先弹窗确认：“删除后照片与草稿将一并清除，确认？”）。

> 💡 Web 端列表上方还有“＋ 新增植物记录”按钮；某个 Tab 没有记录时显示“暂无记录，点击右上角开始你的第一次植物观察”（App 显示“暂无记录，去拍一株植物吧”）。

## 5. 被驳回怎么办？🔁

被老师驳回不等于失败，改一改重新提交就好：

1. 打开**我的植物**（Web 选「被驳回」Tab；App 同样点“被驳回”），找到那条记录。
2. 点 **「继续编辑」**，把不完整的地方补上（照片是否清晰、物种/上报名是否填写、观察时间、必填的动态描述项等）。
3. 确认没问题后点 **「提交审核」**，状态回到**待审核**，重新排队等老师看。

> 老师驳回一条记录时**必须填写意见**。如果列表页面上暂时看不到驳回的具体理由，可以问问老师哪里需要改进（也可以在“消息通知”里留意提醒）。
> 被驳回的记录如果你觉得不需要了，也可以直接 **「删除」**。

## 6. 提交“待鉴定 / 未知植物” 🤔

不认识这株植物、也不确定它叫什么？没关系，照样能提交，让老师帮你鉴定：

- **App 端**：在「补充观察」页的植物搜索框下有一个开关 **「未知植物（待鉴定）」**，把它打开即可。这样**不用填物种名、不用填学名**也可以提交；详情页会显示“未知植物 · 待教师鉴定”。
- **Web 端**：没有这个开关。做法是：**不选**“标准植物”，只在 **「上报名」** 里写一个能描述它的名字（比如“校园路边的紫色小花”），提交后由老师在审核时帮忙鉴定/归类。

> 也就是说：“植物到底叫什么”不是必须由你知道的——先记录好照片、地点、时间、描述，鉴定的事可以交给老师。

## 7. 在地图上找植物 🗺

- **Web 端「中国地图」（3D 立体地图）**
  1. 点顶部导航 **「中国地图」**（或首页的 **「🗺 进入植物地图」**）。
  2. 这是一张 3D 中国地图：每个省份立起来的高度表示该省**公开观察数量**（不是地形高度！）；把鼠标移到省份上能看到“×× 条观察 · ×× 种植物”。
  3. 点某个省，地图会“飞”过去，右侧出现该省的城市/物种面板；点物种还能展开这个省里该物种的观察记录。
  4. 顶部的“全国 › 省份 › 物种”可以逐级返回。
  - **需要浏览器支持 WebGL**。如果浏览器不支持，页面会自动降级成二维省份列表，并提示“当前浏览器不支持 WebGL，已降级为二维省份列表（点击进入该省展廊）”——点击省份卡片即可进入该省展廊。
- **App 端「全国植物」**
  1. 从首页「快捷入口」点 **「全国植物」**（页面标题也是“全国植物”）。
  2. 页面上是**省级列表**：每个省显示“×× 条观察 · ×× 种植物”，点一下省名展开该省植物物种列表。
  3. 再点某个物种，会询问是否打开该物种的全国观察记录，确认后跳到展廊查看。

> 🛡️ 地图页面底部有一句说明（Web 与 App 均有类似内容）：**“地图按学生主动选择的省、市、区县聚合展示，不读取学生设备定位；节点不代表精确采集位置。”** 地图上点到的位置是行政区级别的概览，不是你的精确拍照地点。

## 8. 建议新物种 🌱

在物种库里找不到你观察的植物？可以提交“新物种建议”，老师确认采纳后会**自动建档**加入标准物种库。

- **在哪里提交**：目前该功能在 **App** 上提供——首页「快捷入口」的 **「新物种建议」**，或 **「我的」→「新物种建议」**（页面标题“新物种建议”）。
- **怎么填**：
  1. **建议中文名**（必填或填学名）；
  2. **学名**（可选）；
  3. **描述**：写清叶/花/果特征、生境与发现地点等；
  4. 点 **「提交建议」**。
- **怎么看结果**：页面下方 **「我的建议」** 会列出你提交过的建议及其状态；老师处理后会显示 **“教师回复：××”**。

> 页面开头会提示：“没找到你观察的植物？提交建议，教师确认后会补充到标准物种库。”

## 9. 消息通知 🔔

平台有应用内“消息中心”，用来集中查看平台发给你的消息：

- **Web 端**：学生端左侧菜单 **「消息通知」**，或右上角**铃铛图标**（有未读消息时铃铛上有红点数字）。
- **App 端**：首页「快捷入口」的 **「消息」**，或 **「我的」→「消息通知」**。

消息列表每条会显示**标题、内容、时间**；未读消息在 App 上有绿色标记。没有消息时页面显示“暂无消息”。

> 💡 建议养成习惯：提交记录后隔一天看看消息，及时了解审核结果与老师反馈。

## 10. 隐私与安全提示 🛡️

1. **平台不读取你的位置**：所有省市县都是**手动三级选择**，App 也不会申请定位权限（安装时如果系统询问定位权限，可以选择拒绝）。地图上的位置只是“省/市/区”级别，不会暴露精确地点。
2. **不要在公开内容里写隐私**：观察描述与“详细地点”里**不要写家庭住址、门牌号、学校详细地址**；写“公园南门花坛”“校园操场边”这类大致位置就够了。
3. **姓名的展示规则**：展廊、地图、评论等公开位置会显示观察者姓名。学校管理员可以配置为**脱敏显示**（如“张*”、“欧阳*娜”，姓名越长保留越多），具体以你们学校的配置为准。请放心，展示名字不等于暴露更多个人信息。
4. **照片也要注意**：上传的是植物照片，请避免拍到清晰的他人面部、车牌等无关隐私内容。
5. **尊重他人的照片与记录**：浏览别人的观察时，评论要友善（见第 2 章），评分要实事求是。
6. **保管好账号**：不要把自己的学号/用户名和密码借给别人；在公用电脑/手机上使用后记得**退出登录**。
7. App 只在本地保存登录态与必要的本地草稿，**不保存明文密码**；如果感觉账号异常，第一时间告诉老师。

## 11. 常见问题（FAQ）❓

**Q1：照片传不上去 / 提示“上传失败”？**
- App：先检查网络。照片会在上传前**自动压缩**，正常不会太大；网络不好时先“保存草稿”，照片会自动放入**本地草稿**，等联网后到 **我的植物 → 本地草稿** 点 **「联网同步」** 补传（同步成功前本地草稿不会被删除）。
- 如果上传中途断了，系统会提示“图片上传中断，草稿已保存，可稍后重传”，服务端草稿会保留，你可以在「补充观察」页继续补传照片。
- Web：确认文件是 JPG/PNG/WebP/GIF 格式，且已先保存过一次草稿。
- 还不行？多为服务器或网络问题，联系学校管理员，并参考 [平台运维说明](./plant-platform-operations.md)。

**Q2：网页或 App 里的图片显示不出来（破图/占位图）？**
- 植物图片的地址形如 `/media/plants/...`，需要服务器配置好 **nginx 的 `/media` 转发规则**（把 `/media/plants/` 代理到后端或直接指向图片目录）才能正常显示。如果图片打不开，通常是这台服务器的 `/media` 没配好或后端没启动，请联系管理员排查（细节见 [平台运维说明](./plant-platform-operations.md) 与根目录 `nginx-jingxuan.conf`）。
- 图片本身加载失败时页面会显示 🌿 占位图，不代表记录有问题。

**Q3：网页打开白屏 / 刷新后是空白？**
- 先刷新一次或换个浏览器（推荐 Chrome / Edge）再试；确认网址以 `/jingxuan/` 结尾的正确入口打开。仍白屏则多半是服务端或 nginx 配置问题，联系管理员按运维文档处理。

**Q4：3D 地图打不开 / 提示 WebGL 问题？**
- 3D 地图需要浏览器开启 **WebGL/硬件加速**。可先尝试：换用 Chrome/Edge、在浏览器设置里打开“硬件加速”后重启浏览器。
- 仍不支持时会**自动降级为二维省份列表**，照样能浏览各省数据，不影响使用。

**Q5：我提交的记录为什么在展廊里看不到？**
- 展廊只展示**审核通过**的记录。还在“草稿/待审核/被驳回”状态的记录只有你自己能看到。审核通过后，可能还需要一点时间（或刷新页面）才会出现在展廊与地图中。

**Q6：App 提示“本地待同步草稿 N 条”？**
- 说明你有 N 条在没网络时保存的本地草稿。点提示条跳到 **我的植物 → 本地草稿**，联网后点 **「联网同步」**，成功后本地副本会自动清除。

**Q7：提交审核时报“请填写必填描述项：××”？**
- “××”是老师设置的必填动态描述项（带 * 号），回到编辑页把它填上再提交。

**Q8：忘记密码怎么办？**
- 演示账号请向老师确认；正式使用中如忘记密码，联系老师/管理员重置，不要尝试猜别人密码。

**Q9：还有其他问题？**
- 学生端使用问题优先问老师；涉及服务器、图片、域名等系统问题，请管理员先看 [平台运维说明](./plant-platform-operations.md)，再对照处理。
